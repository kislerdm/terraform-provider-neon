# neon_branch_backup_schedule (Resource)

Manages the automatic snapshot backup schedule for a Neon branch.

## Example Usage

```terraform
resource "neon_project" "example" {
  name = "foo"
}

resource "neon_branch_backup_schedule" "example" {
  project_id = neon_project.example.id
  branch_id  = neon_project.example.default_branch_id
  schedule = [
    {
      frequency         = "weekly"
      day               = 1
      hour              = 4
      retention_seconds = 86400 * 7
    },
    {
      frequency         = "daily"
      hour              = 4
      retention_seconds = 86400
    },
    {
      frequency         = "monthly"
      day               = 1
      hour              = 4
      retention_seconds = 86400 * 30
    },
    {
      frequency         = "monthly"
      day               = 2
      hour              = 4
      retention_seconds = 86400 * 30
    }
  ]
}
```

## Import

The Backup Schedule for a Neon Branch can be imported to the terraform state by its composite identifier that
consists of `ProjectID` and `BranchID` separated by a forward slash.

Import using the [import block](https://developer.hashicorp.com/terraform/language/import):

For example:

```hcl
import {
  to = neon_branch_backup_schedule.example
  id = "curly-poetry-30604233/br-snowy-mountain-a5jkb18i"
}
```

Import using the command `terraform import`:

```commandline
terraform import neon_branch_backup_schedule.example "curly-poetry-30604233/br-snowy-mountain-a5jkb18i"
```
